# 美术比例与像素规范

## 基准

处理后的玩家画布为 24×48 px，脚点 anchor 为 `(0.5, 1.0)`。世界坐标、显示尺寸和排序锚点均使用整数；运行时不再叠加 `0.14` 小数缩放。

| 对象 | 建议世界显示尺寸 | 比例说明 |
|---|---:|---|
| 玩家/NPC | 高 48 | 统一角色基准，宽度按源图原比例。 |
| 普通门可视开口 | 26–31 × 53–67 | 宽约角色 1.0–1.3 倍，高约 1.1–1.4 倍。 |
| 普通桌 | 68–88 × 42–58 | 程序化桌面；桌面接近角色腰部。 |
| 工作书桌 | 82×80 画布 | 只在书写/维修语境使用 `prop_desk`。 |
| 床 | 80×76 | 可视长度约角色高 1.6 倍。 |
| 书架 | 42×75 | 明显高于角色，靠墙放置。 |
| 柜台 | 86×79 | 服务区朝向清晰。 |
| 木桶 | 37×51 | 主体可视高度低于角色；画布包含透视顶部。 |
| 箱子 | 48×47 | 单箱低于角色；堆箱 60×61。 |
| 长椅 | 76×72 | 沿路径或礼仪通道布置。 |
| 小树/树冠 | 90×103 | 碰撞只用树干，树冠可进前景层。 |
| 普通建筑 | 宽 136–242，高 140–252 | 不按旧玩法矩形强制拉伸。 |
| 主钟 | 134×260 | 镇中心竖向锚点，完整留在 648 px 视口内。 |
| 灯塔 | 92×216 | 保持高耸，底座必须落在岸上。 |
| 船/渡船 | 112×118 / 160×144 | 随泊位定向，阴影贴近水线。 |
| 地表/水域 tile | 32×32 | 基础图集以 32 px 网格接入；地图坐标和 region 均为整数。 |
| 室内直墙 | 32×48 | 模块脚点为 `(0.5, 1.0)`；按主题行选择，不做小数缩放。 |
| 室内墙角 | 48×48 | 允许比直墙宽，以保留 3/4 侧面；基线与 48 px 直墙一致。 |
| 墙脚线 | 32×12 | 位于墙面层，不参与地面家具 Y 排序。 |

## 处理规则

- 源图不覆盖；输出统一在 `assets/images/processed/`。
- alpha 裁边后按比例装入整数目标画布，缩放只用 nearest。
- 不用 CanvasItem scale 补偿错误尺寸；变体需要新的 processed 输出规格。
- 摄像机不使用位置平滑；角色和 Sprite 最终位置取整。
- 地面纹理固定世界坐标，不随相机偏移重算 seed。
- 图集通过 `TimeEchoArtCatalog.get_atlas_tile()` 取 region；不要把整张 atlas 当作单个 32 px tile 拉伸。
