# 资产使用规则

1. 运行时只通过 `art_manifest.json` 的 `asset_id` 加载，路径不存在时使用低饱和程序化回退并记录错误。
2. 图片名不构成语义事实；实际画面、视角、文字和比例优先于文件名。
3. 含文字建筑和招牌不得镜像；角色与明确允许的无文字物件才可镜像。
4. `prop_banner` 只作旗帜；不得映射 rug、curtain、quilt 或 blanket。
5. `prop_desk` 只作书写/维修桌；普通餐桌、阅览桌、控制台用程序化结构件。
6. `prop_shelf` 只作高书架；档案柜、钥匙架、控制柜用程序化结构件。
7. `prop_frame` 是立式照片展示架；墙上相框使用程序化像素框。
8. `prop_buckets` 当前禁用，因为图片不是水桶。
9. 建筑、树、船和大型家具默认有接触阴影；小草、花和地毯没有。
10. 相同道具按功能组团，不为了填满空间均匀复制。
11. `source_art/` 只读；所有离线变体必须由 `process_art_assets.py` 生成并带报告。
12. `time_echo_horizon` 只用于标题画面，属于 `concept_only`。
