# 发布检查清单

## 构建与兼容性

- 安装对应 Godot 4.6 Windows 导出模板，执行 `godot --headless --path . --export-release "Windows Desktop"`。
- 在 1024×576、1280×720、1920×1080 和超宽屏检查布局、字号与弹窗。
- 分别验证纯离线、代理未启动、代理中断、限流、超时和在线成功流程。
- 对安装包进行恶意软件误报检查，并在需要时完成代码签名。

## 内容与权利

- 补充项目 LICENSE；在权属确认前不要对外发布源代码许可。
- 记录角色立绘、字体、图标和生成式素材的作者、生成方式、编辑记录及商业使用权。
- 确认 OpenAI API 使用、隐私政策和玩家地区符合发行平台要求。
- 为游戏名称、角色名称和商标完成检索。

## 可访问性与体验

- 验证字号 90%–145%、静音、减少动态、本地 AI 和安全动作快速授权设置能够持久保存。
- 检查所有警告均同时使用文字/图标，不能只依赖颜色或声音。
- 为无线电底噪、短路和低氧声音做峰值与长时间监听测试。
- 至少完成一次不阅读 README 的陌生玩家测试。

## AI 与运营

- 公网代理必须使用 TLS、用户鉴权、服务端密钥、每用户配额和告警。
- 建立中文评测集：明确命令、含糊命令、否定、条件、疑问、撤销、引用、提示注入、人格泄漏和谜题答案泄漏。
- 记录 P50/P95 延迟、远端失败率、本地回退率、动作误解析率和每局模型成本。
- 设置模型不可用时的公告与强制离线开关。

## 回归门槛

- Python、Godot 核心和主流程集成测试全部通过。
- 在线冒烟测试返回 `provider=openai`，含糊问题和否定句均返回无动作。
- 完整相位修复、应急电芯旁路、氧气罐补给、压力调节纠错、关系拒绝/安抚恢复和资源耗尽路线均验证。
- 线索工作台在 1280×720 首屏完整显示，远端与现场线索不会自动泄露最终答案。
