# Blindspot Relay AI NPC 技术升级（v0.4）

本次升级把 AI NPC 从“局部状态 + Prompt”改为“权威模拟器 + 最小权限上下文编译器 + 角色表演与动作提案 + 本地提交”的闭环。

## 运行时边界

1. `MissionSimulation` 独占世界事实、资源、谜题、关系数值、动作合法性与结局。
2. `NpcContextCompiler` 只读取模拟器已经投影出的林岚局部视图，并再次按字段白名单过滤。
3. 上下文分为角色核心、当前场景模式、局部信念、主观记忆、关系、导演意图和最近对话；各区独立限额。
4. 亲眼事实标为 `confirmed_local`；调度员提供的电阻/压力说法标为 `unverified_claim`，携带来源和置信度。
5. 模型只能返回台词、情绪、实际引用 ID 和一个动作候选。玩家授权后，动作仍由本地模拟器重新校验并提交。

## 生成后质量门

模型回复返回后、本地动作解析前还会执行确定性质量检查：

1. 输入已完整解码且场景未声明通信故障时，剥离虚假的“没听清 / 乱码 / 再说一遍”；
2. 玩家明确询问高置信本地事实时，回复必须覆盖相关 `confirmed_local` belief；
3. 回复不得否认自己在 `referenced_ids` 中引用的已确认事实；
4. 不合格回复优先保留剩余角色台词，否则使用该 NPC 已知事实生成保底回答；
5. 触发原因写入 `quality_guard`，随最近 64 轮 trace 保留，不进入角色认知。

## 可观测性

每轮生成 `trace_id`、状态版本、模板版本、硬过滤器、装入的 belief/memory ID、配额裁剪原因和各分区 Token 估算。服务端对真正送往模型的上下文生成 SHA-256 短 hash，并确保原始 trace 元数据不进入角色认知。Godot 保留最近 64 条决策 trace，便于定位泄密、复读、错误动作和模型切换回归。

## 回归门槛

- 调度员独占遥测与随机谜题答案泄漏率：0。
- 多目标含糊指令、否定句、条件句产生动作：0。
- 模型返回非白名单动作或空目标误选：0。
- 权威状态由模型直接修改：0。
- 本地模式、在线失败和熔断后仍能完整通关。

自动化覆盖位于 `tests/python/test_server.py` 与 `tests/godot/mission_simulation_test.gd`；服务端质量与安全回归现为 22 项。
