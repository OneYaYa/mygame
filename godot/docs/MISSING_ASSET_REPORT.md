# 缺失素材报告

机器可读的完整规格位于 `res://data/missing_assets.json`。清单不是笼统的“需要更多素材”，每项均记录资产 ID、目标地图、原生/显示尺寸、视角、色板、数量、当前回退和生产说明。

## P0：结构与统一性

15 项：低噪声草地变体、草地道路边缘、石路边角、自然水岸、深浅水、模块化室内墙体、墙角、墙脚线、普通桌、椅子、礼拜堂长椅、湿石洞穴地面、机械地下室地面、门前平台、建筑/大型物件接触阴影图集。

P0 第一批已完成 8 项：低噪声草地、草路边缘、石路边角、深浅水、三类自然岸线、五主题模块墙体、五主题墙角、五主题墙脚线。规范运行资源与完成映射见 `art_manifest.json`、`missing_assets.json` 和 `P0_BATCH_01_ASSET_SPEC.md`。

P0 尚余 7 项：普通桌、椅子、礼拜堂长椅、湿石洞穴地面、机械地下室地面、门前平台、接触阴影图集。正式程序化回退继续保留，直到这些资产按下一批次生成并完成逐图接入审查。

## P1：场所叙事

11 项：书架变体、工作桌变体、地毯组、旅店前台、档案柜、摄影设备、显影台、钟绳与维修工具、航海图与信号设备、浮标、洞穴岩石与积水边缘。

这些项目主要降低现有单件道具的重复率，并让相馆、档案馆、港务室和机械空间进一步区别。当前回退全部按正确语义绘制，没有使用 banner 代替地毯、desk 代替所有桌子或 shelf 代替所有柜体。

## P2：氛围

7 项：烟雾、水面高光、尘埃、落叶、鸟、昆虫、天气/季节覆盖。当前水面高光与部分地面细节已用世界坐标和固定 seed 轻量绘制，其余未启用，避免在素材不足时增加噪声或 Web 渲染成本。

## 生产约束

- 一律使用 `top_down_three_quarter` 或清单明确标出的俯视子视角。
- 不复制商业游戏构图或素材，不使用来源不明的网络资源。
- 像素素材使用整数画布与 nearest；动画低帧率、低粒子数量。
- 新源图进入 `source_art/` 后只读保存，通过 `tools/process_art_assets.py` 生成 processed 版本并登记来源。
- imagegen 母版保存在 `source_art/generated/masters/`，规范化 source 保存在 `source_art/generated/`；二者不得互相覆盖。
